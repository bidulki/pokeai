# pokeai
이 프로젝트는 포켓몬스터의 팬게임으로 NPC와 포켓몬에 생성형 AI를 접목시켜,
유저의 행동과 말에 반응하여 변화하는 게임을 목표로 하고 있습니다.

# 실행방법  
```
conda create -n poke --python=3.9
cd poke
pip install -r requirements.txt
cd games
python main.py
```
